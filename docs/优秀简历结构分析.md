# 优秀简历结构分析报告

> 数据来源：① 研究结论（Jobscan/Rezi/超级简历等成熟产品方法论 + 多篇简历写作规范）② 抓取自 GitHub `ResumeSample`（2.5w star）的 8 个岗位技能关键词词频表（670 条，从数百份真实 JD 统计）③ 程序化生成的 100 篇结构规范样本。数据已入库 `offerflow.db`（`resume_samples` / `resume_skill_keywords`）。

## 一、优秀简历的通用骨架（分节顺序）

优秀简历不是流水账，而是「一页 A4 内、按 HR 阅读路径排列的论证」。标准模块顺序：

| 顺序 | 模块 | 应届生 | 社招（3 年+） |
|---|---|---|---|
| 1 | 姓名 + 联系方式 | ✅ 顶部 | ✅ 顶部 |
| 2 | 求职意向 / 目标岗位 | ✅ | ✅ |
| 3 | 核心摘要（2-3 句） | 可选 | ✅ 建议 |
| 4 | 教育经历 | ✅ **前置** | 后置 |
| 5 | 项目 / 实习 / 工作经历 | 核心 | **核心（前置）** |
| 6 | 技能清单 | ✅ | ✅ |
| 7 | 证书 / 荣誉 | ✅ | 精简 |

**关键规则**：应届生教育前置（你无工作经验，学历是最大资本）；社招经历前置（能力由经历证明）。

## 二、内容写法：三条铁律

### 1. 动词开场，杜绝「负责/参与」

弱动词 `负责`、`参与`、`协助` 是简历最大的通病。替换为强动词：

| 弱 | 强 |
|---|---|
| 负责开发 | 主导 / 重构 / 搭建 / 落地 |
| 参与优化 | 优化 / 设计 / 重构 |
| 协助完成 | 推动 / 交付 / 孵化 |

### 2. 量化锚点：把「很多」写成「数字」

「明显提升」「大量用户」是无效信息。量化公式：**动词 + 方法 + 量化结果（含基线）**。

- ❌ 使用 Docker 容器化部署
- ✅ 将部署时间从 2 小时缩短到 7 分钟

量化维度：QPS/响应时间/DAU/转化率/成本/人数/金额/覆盖率。

### 3. STAR + 结果导向

每条要点 = 情境 + 动作 + **结果**。不写「做了什么」，写「改变了什么」。每条 bullet 1-2 行、每个经历 2-3 条 bullet。

## 三、ATS 关键词规律（真实词频数据）

从 `resume_skill_keywords` 表提取的各岗位高频关键词 TOP 5（从数百份真实 JD 统计）：

| 岗位 | TOP 5 关键词（词频） |
|---|---|
| Java 开发 | java(730)、spring(305)、web(260)、mysql(250)、oracle(207) |
| Web 前端 | web(889)、javascript(596)、css(555)、html(486)、jquery(389) |
| Android | android(1830)、java(386)、ui(180)、jni(96)、framework(92) |
| iOS | ios(1383)、iphone(312)、app(276)、object-c(201)、swift(159) |
| PHP | php(959)、mysql(525)、web(280)、linux(207)、javascript(187) |
| Node.js | js(129)、nodejs(105)、node(97)、javascript(72)、mongodb(69) |
| 架构师 | java(364)、web(219)、mysql(186)、redis(159)、spring(157) |
| C/C++ | linux(369)、windows(178)、mysql(110)、c++(98)、tcp(91) |

**规律**：① 每个岗位有 1-2 个「锚点词」（如 Java 岗的 java、前端岗的 web），其余是「生态词」（框架/中间件/工具）。② ATS 先扫锚点词和 JD 原词，再扫生态词。③ **技能清单要同时覆盖锚点词 + 生态词 + JD 里的原词**，不要写「熟练 Office」这类无效词。

## 四、格式与一页约束

| 项 | 规范 |
|---|---|
| 长度 | 一页 A4（应届/3 年内经验）；资深岗可两页 |
| 字体层级 | 姓名 16-18pt > 模块标题 12-14pt > 正文 10-11pt |
| 对齐 | 统一左对齐、单栏、无花哨图形表格（利于 ATS 解析） |
| 强调 | 只对「岗位关键词、关键数字」加粗，每页 ≤10 处 |
| 导出 | PDF（防止版式错乱） |
| 文件名 | `姓名-岗位-年限-亮点.pdf` |

**核心认知**：一页纸不是「写不下」，而是「想清楚什么最重要」。内容多时优先删废话/并同类/删无关经历，**而非缩小字体**。
