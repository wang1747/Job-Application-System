# 简历模块接口设计

简历模块已拆分为独立子模块，各子模块只通过明确接口传递信息，不互相读取内部实现。

## 目录

```text
backend/app/modules/resume/
├── routes.py           # HTTP 接口层，只负责参数解析和响应包装
├── services.py         # 业务编排层，调用 parser / optimizer / export
├── parser.py           # 文件解析，不依赖数据库和其他业务模块
├── export_service.py   # PDF / Word 导出
└── optimizer/
    ├── contracts.py    # 对外数据结构（ResumeSection / OptimizationResult / PreservationResult）
    ├── sections.py     # 分块 + 内容保留校验（纯函数）
    ├── prompts.py      # 提示词
    └── service.py      # LLM 调用与结果合并
```

## 调用链

`routes.py -> services.py -> optimizer/service.py`

## 关键约束

- 优化必须基于原始简历逐块改写，输出前做内容保留校验。
- 校验未通过时自动回退为原简历，绝不输出编造内容。
- 上传文件解析为空时直接返回 400，避免空原文进入优化流程。
